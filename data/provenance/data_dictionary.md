# Data dictionary

- **N/P/K**: source benchmark scale; physical units unverified
- **temperature**: Celsius
- **humidity**: percent
- **ph**: pH
- **rainfall**: mm
- **area**: hectares
- **production**: tonnes for retained crops
- **yield**: tonnes/hectare

Regional year strings use the starting calendar year. Source yield column is recomputed. Current published files are community snapshots, not independent field measurements.
