One prediction.
Three entry points.

The browser, CLI and MCP tools use the same validation and trained models. This explorer works offline with your local server.

Full OpenAPI schema

Endpoints

  • GET /api/health — model readiness
  • GET /api/model-info — scope, metrics and limitations
  • GET /api/coverage?state=…&district=…&season=… — historical coverage
  • GET /api/example — historical demonstration input
  • GET /api/weather?latitude=…&longitude=… — optional external weather context
  • POST /api/predict?explain=true — required JSON request, ranked crops, supported yields, explanations and warnings

Try a prediction

All twelve fields are required. Unknown fields, numeric strings, invalid ranges and non-finite numbers are rejected. Year must be a JSON integer. Errors return 422; weather failures return 503.

Response

Load the example and submit to see the response.

Not agronomic advice. Crop probabilities are benchmark suitability; yield is historical. No input data are stored by the server.
